# ZephVanIterson.github.io

Personal portfolio website for Zeph Van Iterson, hosted with GitHub Pages.

## Local preview

From the repository root, run:

```sh
python -m http.server 8000
```

Then open `http://localhost:8000` in a browser.

## Structure

- `index.html` contains the site content and semantic structure.
- `styles.css` contains the responsive light and dark themes.
- `script.js` controls theme selection, mobile navigation, and active navigation states.
- `ZephVanItersonResume.pdf` is linked from the hero section.
- `sitemap.xml` lists the canonical page for search engines.
- `robots.txt` permits crawling and advertises the sitemap.

GitHub Pages publishes the repository from the configured deployment branch.
